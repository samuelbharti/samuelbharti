### Hi, I’m Sam 👋

I’m a product-minded computational biologist. I like building tools that make omics data easier to explore, trust, and share.
I build interactive apps and AI-assisted tools for genomics and multi-omics integration, spanning bulk, single-cell, and Perturb-seq RNA-seq through whole-exome data, with a focus on modular design and reproducible workflows.

#### Featured projects

**Agentic AI for science**
- **genescout**: turn a candidate gene list + disease context into a ranked, evidence-supported review. Deterministic keyless core, optional Claude agent layer.
  Repo: https://github.com/samuelbharti/genescout · Hackathon: https://www.samuelbharti.com/claude-science-hackathon.html
- **biobouncer**: a gate for biological inputs that validates gene symbols, ontology terms, variant formats, and database identifiers.
  Repo: https://github.com/samuelbharti/biobouncer · Docs: https://www.samuelbharti.com/biobouncer/
- **RAPTOR**: agentic system that extracts phenotypes, genes, diseases, and ontology-linked concepts from unstructured patient records (unreleased).
